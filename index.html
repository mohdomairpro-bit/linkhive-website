Staying safe with scripts

A few habits worth keeping regardless of where a script comes from.

  • Only grab scripts from sources you actually trust — this site, or people you know.
  • We will never ask for your Roblox password or account details for any reason.
  • Anything promising free Robux isn't a script doing that — treat it as a scam.
  • Keep antivirus software active and scan anything you download before opening it.
  • Check a game's rules before using something that changes how it plays.
